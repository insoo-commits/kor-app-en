首都圈

首尔、仁川和 경기도 gyeonggido (京畿道) 合称 수도권 sudogwon (首都圈)。全国将近一半的人住在这里。

很多公司、大学和工厂也在这个地区。

方言

每个地区都有自己的方言 사투리 saturi，就像中国各地也有不同的方言一样。

电视上和课堂上用以首尔话为基础的标准韩语 표준어 pyojuneo。

城市之间的交通

KTX 高铁从首尔到釜山约两个半小时，到全州约两小时。

高速巴士 고속버스 gosokbeoseu 更便宜，班次也多。可以在应用里买票。

了解一下 알아 두면 좋아요

和中文地址一样，韩国地址从大到小：도 或 시 → 구 → 路 → 楼号。英文地址通常顺序相反。

常用句子 이렇게 말해요

저는 전주에 살아요.
我住在全州。
서울에서 전주까지 기차로 가요.
我坐火车从首尔去全州。

怎么看韩国地址 주소 읽기

地址从大到小：道/市 → 区 구 → 路 로/길 → 号码。寄包裹需要5位数的邮政编码。

城际交通 시외 교통

高铁 KTX 从首尔到釜山约两个半小时。高速巴士 고속버스 更便宜，通往所有城市。在 코레일톡 应用或客运站买票。

在韩国的留学生 한국의 유학생

留学生不只在首尔，而是住在韩国各地。像全州大学一样，大多数大学都有国际交流处和学生社团，可以在那里交朋友。
