음성 저장과 오프라인
အသံ သိမ်းရန် 음성 앱에 저장စက်ထဲ အသံ အားလုံး သိမ်းရန် စာမျက်နှာ အောက်ခြေရှိ ⤓ ကို နှိပ်ပါ။ ပထမအကြိမ် အချိန် အနည်းငယ် ကြာပါသည်။ ထို့နောက် အင်တာနက် မရှိဘဲ နားထောင်နိုင်ပါသည်။
Home Screen တွင် ထည့်ခြင်းiPhone: Safari → Share ခလုတ် → Add to Home Screen။ Android: Chrome → Menu → Install app။
အပ်ဒိတ်များဗားရှင်းအသစ် ရရန် app ကို လုံးဝ ပိတ်ပြီး ပြန်ဖွင့်ပါ။ ဗားရှင်း နံပါတ်သည် စာမျက်နှာ အောက်ခြေတွင် ရှိပါသည်။
အပြင်အဆင် · စာလုံး အရွယ် 화면 · 글자 크기စာမျက်နှာ အောက်ခြေတွင်: အလိုအလျောက် / အလင်း / အမှောင် နှင့် စာလုံး ကြီးရန် A− မှ A++ အထိ။
လေ့လာမှု မှတ်တမ်းနောက်ဆုံး ဖွင့်ခဲ့သော သင်ခန်းစာနှင့် သင့် ဆက်တင်များကို ဤစက်တွင်သာ သိမ်းပါသည်။
အသုံးပြုမှု စာရင်းအင်း 사용 통계app ကို တိုးတက်စေရန် အမည်မဖော်သော အရေအတွက်များကို ပို့ပါသည်: ဖွင့်သော သင်ခန်းစာများ၊ ပဟေဠိ ရမှတ်များ၊ ရက်စွဲနှင့် အချိန်၊ စက် အမျိုးအစား (ဖုန်း၊ တက်ဘလက် သို့မဟုတ် ကွန်ပျူတာ)။ အမည်၊ အီးမေးလ် သို့မဟုတ် တည်နေရာ မပို့ပါ။ သင့်စက်သည် ကျပန်း နံပါတ်တစ်ခုသာ ရပါသည်။ 이름·이메일·위치는 보내지 않고, 기기마다 무작위 번호만 씁니다.
