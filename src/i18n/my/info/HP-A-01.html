မိတ်ဆက် ဗီဒီယို ကြည့်ရန် (3:38, အင်္ဂလိပ်) 소개 영상

ဘယ်သူတွေအတွက်လဲ

JeyCampus သည် ဂျွန်ဂျူ တက္ကသိုလ် အင်္ဂလိပ် သင်ရိုးရှိ နိုင်ငံခြား ကျောင်းသားများအတွက် ကိုရီးယားစကား သင်ယူရေး အက်ပ် ဖြစ်ပါသည် 영어 트랙 유학생을 위한 한국어 앱။ ရှင်းလင်းချက်များကို မြန်မာလို ရေးထားပြီး ကိုရီးယားစကား ဘေးတွင် ပါပါသည်။

JeyJey နှင့် တွေ့ဆုံပါ 제이제이와 친구들

JeyJey သည် သင်နှင့်အတူ ကိုရီးယားစကားနှင့် ကျောင်းဘဝကို သင်ယူပါသည်။ ပဟေဠိ ဖြေပြီးတိုင်း JeyJey က အားပေးပြီး Byeori နှင့် Jate လည်း ကူညီပါသည်။ 제이제이가 함께 공부하고 응원해요.

ဂျွန်ဂျူ တက္ကသိုလ် 전주대학교

ဂျွန်ဂျူ တက္ကသိုလ်သည် မိမိကိုယ်ကို JJ University၊ “စူပါစတား များ၏ နေရာ” 수퍼스타를 키우는 곳 ဟု ခေါ်ပါသည်။ အမှတ်တံဆိပ်မှာ စတုရန်းနှင့် ကြယ် ဖြစ်ပြီး ကျောင်းသားတိုင်း စူပါစတား ဖြစ်လာနိုင်သည်ဟု ဆိုလိုပါသည်။ ကျောင်းဝင်း တစ်ခွင်လုံးတွင် ကြယ်များကို တွေ့ရပါမည်: အဆောင်များမှာ Star Tower၊ Star Ville နှင့် Star Home ဖြစ်ပြီး JeyJey လည်း ကြယ် ဆင်ထားပါသည်။ 학생 한 사람 한 사람이 수퍼스타가 되는 곳이에요.

သင်ယူပုံ

အကြောင်းအရာများကို ခေါင်းစဉ်အလိုက် သင်ခန်းစာ ငယ်များအဖြစ် ခွဲထားပါသည်။ သင်ခန်းစာတိုင်းတွင် စကားလုံး၊ ဥပမာ ဝါကျ၊ စကားပြော တိုများနှင့် ပြန်လှန်လေ့ကျင့်ရန် မေးခွန်းများ ပါပါသည်။ နားထောင်၊ စကားလုံးကတ်များ ကြည့်ပြီး ကိုယ့်ကိုယ်ကို စမ်းသပ်ပါ။

ဘယ်နေရာမှာမဆို သုံးပါ

ဖုန်းနှင့် ကွန်ပျူတာ နှစ်မျိုးလုံးတွင် အလုပ်လုပ်ပါသည်။ အသံကို စက်ထဲ သိမ်းထားလျှင် အင်တာနက် မရှိဘဲ နားထောင်နိုင်ပါသည်။

အက်ပ် ထည့်သွင်းခြင်း 앱 설치하기

JeyCampus သည် ဝဘ် အက်ပ် ဖြစ်သဖြင့် app store မရှိပါ။ လိပ်စာကို တစ်ကြိမ် ဖွင့်ပြီး home screen တွင် ထည့်ပါ။ ထို့နောက် အခြား အက်ပ် များကဲ့သို့ ကိုယ်ပိုင် icon မှ မျက်နှာပြင်အပြည့် ပွင့်ပါမည်။ 주소를 한 번 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

  3. Add to Home Screen 홈 화면에 추가 ကို နှိပ်ပြီး Add 추가 ကို နှိပ်ပါ။
Android (Chrome)
  1. လိပ်စာကို Chrome တွင် ဖွင့်ပါ။
  2. ညာဘက် အပေါ်ရှိ မီနူး ⋮ ကို နှိပ်ပါ။
  3. Install app 앱 설치 သို့မဟုတ် Add to Home screen 홈 화면에 추가 ကို နှိပ်ပြီး Install 설치 ကို နှိပ်ပါ။
ကွန်ပျူတာ (Chrome · Edge)
  1. လိပ်စာကို ဖွင့်ပါ။
  2. လိပ်စာဘား ညာဘက်အစွန်ရှိ install icon ကို နှိပ်ပါ၊ သို့မဟုတ် မီနူး ⋮ ကို ဖွင့်ပြီး Install JeyCampus 설치 ကို ရွေးပါ။
